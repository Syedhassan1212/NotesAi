1️⃣ Basic Counter (easy)

Make a component Counter with +1, -1, reset buttons.

Start count at props.initialCount (default 0).

✅ Goal: use props + useState together.

2️⃣ Name Changer (medium)

Make a component NameChanger:

Initial name comes from props (like "Hassan").

Input box lets you type a new name → update useState.

Button to reset to original props value.

Extra: show “Hello, [name]!” live as you type.

3️⃣ Todo List (spicy)

Component TodoList:

Starts with props.initialTodos = ["Eat", "Sleep"].

Add input box + button to add new todo → update state.

Each todo has a delete button.

Bonus: reset button to go back to initialTodos from props.

4️⃣ Optional challenge (level: boss mode)

Combine all three:

App passes initial count, initial name, and initial todo array as props.

Child component has useState for each.

Buttons / inputs update state independently.
